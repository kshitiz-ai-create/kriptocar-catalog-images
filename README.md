# kriptocar-catalog-images

Product photos for the Kripto Car WhatsApp / Meta catalog. Meta loads these by URL, so do not rename or delete files that are live in the catalog.

- `galio/` – Galio GFX products, named by Galio part number (e.g. `GLCM-015.jpg`)
- `dhc/` – DHC infotainment players, named by DHC model code or `DHC-<model>`; `-car.jpg` = in-car photo
